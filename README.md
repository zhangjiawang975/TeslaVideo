# TeslaVideo

特斯拉行车记录仪（TeslaCam / 哨兵模式）视频播放与剪辑导出工具，Windows 桌面客户端。

插上特斯拉 U 盘（或打开拷贝出来的 `TeslaCam` 目录），像车机上的行车记录仪查看器一样按 **哨兵 / 保存 / 最近** 浏览事件，多视角同步回放；选好视角、拖动时间轴左右边界框选片段，导出单视角 MP4——可以选**与原文件逐帧一致的原画无损**，也可以选**带真实时间戳水印**。

> 参考了 [Mario34/tesla-camera](https://github.com/Mario34/tesla-camera) 的思路（ffmpeg drawtext 叠加时间码）；车辆数据格式来自特斯拉官方公开的 [teslamotors/dashcam](https://github.com/teslamotors/dashcam)。代码均为重新实现。

## 功能

### 浏览（仿车机）
- **自动识别 U 盘**：启动时优先打开上次的目录；没有的话自动查找插着的特斯拉 U 盘（任意盘符下的 `TeslaCam`）。也可以点文件夹按钮或把文件夹拖进窗口。
- **分类**：全部 / 哨兵（`SentryClips`）/ 保存（`SavedClips`）/ 最近（`RecentClips`），显示各类数量。
- **事件卡片**：按日期分组，显示缩略图（`thumb.png`；最近行程用前视角画面）、时间、触发原因（物体靠近、鸣笛保存、语音保存、手动保存……）、地点和时长。
- **一个事件 = 一条完整时间轴**：特斯拉把录像切成约 1 分钟的文件，程序把同一事件的所有文件连起来播放（约 10 分钟）；`RecentClips` 里平铺的文件会按时间连续性自动拆分成一段段行程。时间轴上的细竖线是文件分界，红点是事件发生时刻，打开哨兵/保存事件时自动定位到事件前 10 秒。

### 回放
- **多视角同步**：大画面是当前视角，其余视角以缩略图同步播放，点击缩略图或按数字键切换。支持前 / 后 / 左右翼子板，以及新车型的左右 B 柱摄像头；某段缺少某个视角时显示“该时段无画面”。
- **顶部信息栏**：左侧是当前帧的真实拍摄时间（与导出水印算法一致）；右侧是仿车机风格的车辆数据：车速、左右转向灯（绿色闪烁）、档位 P R N D、加速踏板百分比、刹车（亮红）。车辆数据来自特斯拉写在每一帧里的 SEI 元数据（固件 2025.44.25+、HW3+，停车哨兵时通常没有），没有数据时自动隐藏；**只在预览时显示，不会进入导出的视频**。
- 0.5×～8× 倍速、键盘快捷键。

### 区间截取（类似剪映）
- 时间轴左右两个手柄拖动框选，拖动时画面跟着跳到对应帧；也可以按 `I` / `O` 把播放头位置设为起点 / 终点。
- **可以跨文件选择**，选区不受 1 分钟文件边界限制。
- **滚轮缩放时间轴**：长行程（几十分钟）上用滚轮以鼠标位置为中心放大，精确框选；双击时间轴还原；播放时视图自动跟随。
- 显示起点、终点的真实时间和选区时长（悬停可看事件内的相对时间，精确到 0.01 秒）。

### 导出
只导出**当前主视角**，MP4 格式，显示进度、可取消，完成后一键打开所在文件夹，同名文件不会被覆盖。两种方式：

| | 原画无损 | 带时间水印 |
| --- | --- | --- |
| 画质 | 直接复制原始画面数据，**与行车记录仪原文件逐帧逐字节一致**（已用 MD5 逐帧验证） | 重新编码（x264 CRF 16 / slow），实测 PSNR ≈ 46 dB、SSIM ≈ 0.992，肉眼无差别，但属于二次编码 |
| 时间戳 | 画面不加水印（文件名带起点时间） | 左上角烧录 `YYYY-MM-DD HH:MM:SS` |
| 起点 | 对齐到起点之前最近的关键帧（特斯拉约每 0.5～1 秒一个），会稍微多出一点 | 帧级精确 |
| 速度 / 体积 | 几乎瞬间完成，体积与原片相当 | 需要编码，体积约为原片 2.3 倍 |
| 适合 | **交警举报、保险理赔等需要原始证据的场合** | 分享、需要画面上直接看到时间 |

输出文件名：`<起点真实时间>_<视角>.mp4`，原画模式为 `<起点真实时间>_<视角>_原画.mp4`。

## 时间戳的准确性

1. **时间基准**：特斯拉文件名里的时间（例如 `2026-10-03_13-23-08-front.mp4`）就是这个文件第一帧的本地拍摄时间，与 MP4 元数据里的 `creation_time` 一致。
2. **与电脑时区无关**：文件名时间按“墙上时间”处理，用 UTC 方式换算和格式化（ffmpeg `pts:gmtime`），无论电脑时区、夏令时如何，显示的都是车上的本地时间。
3. **事件时间轴按真实时间排布**：每个文件放在“文件起始时间 − 事件起始时间”的位置上，特斯拉文件之间约 1 秒的录制空隙被如实保留，所以时间轴上任何位置的时间都等于“事件起始时间 + 位置”。
4. **截取和拼接不偏移**：带水印导出时，选区被拆成每个文件内的片段，各自用 `-ss` 精确截取，并用“该文件起始时间 + 截取起点”作为水印偏移，再拼接起来；每一帧水印都等于该帧的真实拍摄时间。
5. **保留原始帧时间**：特斯拉视频是可变帧率，导出时保留每一帧的原始时间（`-fps_mode passthrough -enc_time_base demux`），不会因为重采样造成漂移。

已在实际素材上验证：从 10.5 秒截取时，原视频第 11.0 秒那一帧的水印准确地从 `13:23:18` 跳到 `13:23:19`；跨文件导出时，前一个文件最后一帧是 `21:58:25`，下一个文件第一帧是 `21:58:26`，与真实录制时间一致。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `空格` | 播放 / 暂停 |
| `←` / `→` | 后退 / 前进 1 秒（按住 `Shift` 为 5 秒） |
| `,` / `.` | 逐帧后退 / 前进 |
| `I` / `O` | 把当前位置设为起点 / 终点 |
| `1`～`6` | 切换主视角 |
| 滚轮（时间轴上） | 缩放时间轴，双击还原 |

## 使用方法

1. 插上特斯拉 U 盘，运行 `TeslaVideo-<版本号>\TeslaVideo.exe`（无需安装，整个文件夹可以直接拷到其他电脑使用），程序会自动找到 U 盘里的 `TeslaCam`。
2. 在左侧选分类和事件，点击缩略图切换到想要的视角。
3. 拖动时间轴两端的手柄框选区间（长视频可以先用滚轮放大时间轴）。
4. 选择导出方式（原画无损 / 带时间水印），点击“导出 MP4”；第一次导出时需要选择保存目录。

## 技术方案

- **Electron**：界面使用原生 HTML/CSS/JS，不依赖前端框架和打包器；Chromium 自带 H.264 解码，可以直接播放特斯拉视频。
- **ffmpeg**（[BtbN 的 GPL 构建](https://github.com/BtbN/FFmpeg-Builds)，自带 libx264、freetype）：负责截取、拼接、叠加水印和编码，随程序一起打包。
- **electron-builder**：打包为 Windows x64 免安装程序目录。

```
TeslaVideo/
├─ src/
│  ├─ main.js        # 主进程：窗口、事件扫描与分组、U 盘识别、调用 ffmpeg 导出
│  ├─ mp4.js         # 轻量 MP4 解析：只读文件尾部的 moov，取时长、帧表、关键帧
│  ├─ telemetry.js   # 读取每帧 SEI 里的车辆数据（protobuf）
│  ├─ preload.js     # 给渲染进程暴露的安全 IPC 接口
│  ├─ index.html     # 界面
│  ├─ style.css
│  └─ renderer.js    # 事件列表、跨文件连续播放、多视角同步、时间轴截取与缩放、导出
├─ scripts/
│  ├─ fetch-ffmpeg.js  # 下载 ffmpeg.exe 到 bin/
│  └─ rename-dist.js   # 把打包目录 win-unpacked 改名为 TeslaVideo-<版本号>
├─ bin/ffmpeg.exe    # 构建时放入（不提交到仓库）
└─ package.json
```

## 开发与构建（Windows）

需要 Node.js 18 及以上版本。

```bat
npm install
npm run fetch-ffmpeg   :: 下载 ffmpeg.exe 到 bin\（已存在则跳过）
npm start              :: 开发模式运行
npm run dist           :: 打包，产物在 dist\TeslaVideo-<版本号>\
```

打包产物是免安装的程序目录 `dist\TeslaVideo-<版本号>\`，双击其中的 `TeslaVideo.exe` 运行。版本号取自 `package.json` 的 `version`，发布新版本时改这里即可。

## 已知限制

- 特斯拉的数据格式里虽然定义了逐帧的经纬度和航向，但实测国内车辆的视频里这几个字段都是空的，所以无法显示行驶方向；地点只有 `event.json` 里事件那一刻的估算坐标。
- 时间戳精度受文件名限制，只精确到秒（这是特斯拉文件本身能提供的最高精度）。
