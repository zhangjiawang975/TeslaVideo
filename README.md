# TeslaVideo

特斯拉行车记录仪 / 哨兵模式视频的播放与剪辑导出工具（Windows）。像车机一样按事件浏览、多视角同步回放，框选片段后导出当前视角的 MP4。

## 下载

在 [Releases](https://github.com/zhangjiawang975/TeslaVideo/releases) 下载 zip，解压后运行 `TeslaVideo.exe`（需保留整个文件夹）。首次运行若提示“Windows 已保护你的电脑”，点 **更多信息 → 仍要运行**。

程序启动时会检查 GitHub 上的新版本，有更新会在底部提示，点 **立即更新** 即可自动下载、替换并重启（v1.0.1 起支持）。

插上特斯拉 U 盘会自动识别 `TeslaCam`，也可以手动选择或拖入文件夹。程序只读取视频，不会修改 U 盘内容。

## 功能

- **按事件浏览**：全部 / 哨兵 / 保存 / 最近，同一事件的多个 1 分钟文件连成一条时间轴，自动定位到事件发生前 10 秒。
- **多视角同步**：点击缩略图或按数字键切换主视角。
- **车辆数据**：显示车速、档位、转向灯、踏板、刹车（需较新固件；仅预览显示，不进入导出视频）。
- **区间截取**：拖动时间轴两端手柄框选，可跨文件；滚轮缩放时间轴，双击还原。
- **导出**：只导出当前主视角，两种方式（默认带时间水印）：

| | 带时间水印（默认） | 原画无损 |
| --- | --- | --- |
| 画质 | 高画质重新编码，肉眼无差别 | 与原文件逐帧完全一致 |
| 时间 | 烧录在画面左上角 | 只写在文件名里 |
| 起点 | 精确到帧 | 对齐到前一个关键帧（最多早约 1 秒） |
| 适合 | **交警举报**（要求画面带时间）、分享 | 留存原始素材备查 |

水印时间按“文件名中的录制时间 + 帧位置”逐帧计算，与电脑时区无关，跨文件也准确（精度为秒，受特斯拉文件名限制）。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `空格` | 播放 / 暂停 |
| `←` `→` | 后退 / 前进 1 秒（`Shift` 为 5 秒） |
| `,` `.` | 逐帧后退 / 前进 |
| `I` `O` | 设为起点 / 终点 |
| `1`～`6` | 切换主视角 |

## 构建

需要 Node.js 18+，在 Windows 上执行：

```bat
npm install
npm start       :: 开发运行
npm run dist    :: 打包到 dist\TeslaVideo\ 和发布用的 zip（首次会自动下载 ffmpeg）
```

基于 Electron + ffmpeg。车辆数据格式参考特斯拉官方 [teslamotors/dashcam](https://github.com/teslamotors/dashcam)，思路参考 [Mario34/tesla-camera](https://github.com/Mario34/tesla-camera)。
